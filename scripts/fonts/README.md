Subsets (ASCII + a few symbols) embedded into the SVGs as data URIs, because SVGs shown via `<img>` on GitHub cannot load web fonts.

- `mono*.woff`: Anonymous Pro, SIL Open Font License 1.1 (see OFL-AnonymousPro.txt)
- `display.woff`, `sans.woff`: Inter Display ExtraBold / Inter Medium, SIL Open Font License 1.1 (https://github.com/rsms/inter)
